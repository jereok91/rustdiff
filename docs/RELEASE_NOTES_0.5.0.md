# RustDiff 0.5.0

Tag: `v0.5.0`.

RustDiff moves from GTK4 + Libadwaita to a **Tauri v2** app with a React
interface. The diff engine, the parsers, the history database and the
settings file are the same code as in 0.4.0, so upgrading needs no
migration: your history and preferences are picked up as they are.

## What changed for users

### A new interface

- **Editors**: CodeMirror 6 with syntax highlighting for JSON, XML and SQL,
  line and character-level diff highlighting, pretty-print
  (`Ctrl+Shift+F`) and in-editor search (`Ctrl+F`).
- **Differences panel**: the same filterable table with click-to-jump, now
  in a resizable panel that still collapses with `Ctrl+D`.
- **Graph view** (`Ctrl+G`): redrawn on a 2D canvas on top of the same
  layout engine — pan, zoom, zoom-to-fit, node search and node inspection.
- **Design system**: light and dark themes (follow the system or pick one),
  consistent diff colors that pass WCAG AA contrast, keyboard-accessible
  controls with visible focus. Reference: `docs/design-system.md`.
- History, export to `.txt`/`.html`, the exit dialog, the language picker
  (English/Spanish) and the UI text size (`Ctrl++`, `Ctrl+-`, `Ctrl+0`) work
  as before.

### Removed

- The **"Open History"** action of the desktop entry (`rustdiff --history`).
  It never worked in 0.4.x either: the flag was declared in the `.desktop`
  file but not implemented.

## What changed for packagers and installers

| Channel | 0.4.x | 0.5.0 |
| --- | --- | --- |
| Flathub | GTK app on `org.gnome.Platform//50` | Tauri app on the same runtime (WebKitGTK 4.1 comes with it); frontend bundle attached to the release |
| `.deb` / APT | `cargo-deb`, depends on GTK4 + libadwaita + GtkSourceView | Tauri bundler, same package name `rustdiff`, depends on `libwebkit2gtk-4.1-0` + `libgtk-3-0`; Ubuntu 24.04+ / Debian 13+ |
| macOS | DMG bundling the Homebrew GTK stack | DMG from the Tauri bundler, no bundled libraries (system WebKit) |
| Homebrew cask `rustdiff-app` | yes | yes, unchanged for users |
| Homebrew formula `rustdiff` | source build with `cargo install` | **retired**, use the cask |
| crates.io | `cargo install rustdiff` | **retired**: 0.4.x stays there as the last GTK release |
| `install.sh` | `cargo install rustdiff` | `.deb` on Debian/Ubuntu, source build (pnpm + cargo) elsewhere |

Building from source now needs Node.js 20+ and pnpm next to Rust, and
WebKitGTK 4.1 instead of GTK4/libadwaita/GtkSourceView (see the README).

## Under the hood

- The repository root is a virtual Cargo workspace: `crates/rustdiff-core`
  (parsing, diff, graph layout, export), `crates/rustdiff-persist` (history
  and settings) and `desktop/src-tauri` (the app, binary `rustdiff`).
- The frontend talks to the core only through typed Tauri commands
  (`desktop/src/bindings.ts`, generated by `tauri-specta`); it never touches
  the filesystem, so the 10 MB input limit and the typed errors stay in Rust.
- Measured during the migration: the window maps in about 0.2 s, and the
  process tree uses about 1.9× the memory of the GTK app (WebKit's web and
  network processes).
